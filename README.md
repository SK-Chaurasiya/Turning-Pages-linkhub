# Turning Pages Linkhub

**🟢 Live Demo:** [turningpage-linkhub.netlify.app](https://turningpage-linkhub.netlify.app/)

A premium, bespoke digital portfolio and link-in-bio alternative crafted specifically for the atmospheric music creator, Turning Pages. This custom landing page routes traffic to various platforms while providing an immersive, brand-aligned visual experience.

## Features
* **Cinematic Aesthetic:** Dark theme utilizing glassmorphism UI elements and animated floating background layers.
* **Interactive Cursor:** Custom JavaScript-driven cursor trail that reacts to interactive elements.
* **Media Integration:** Embedded Spotify player for immediate, on-page auditory immersion.
* **Smooth Animations:** Scroll-triggered fade and scale effects utilizing the Intersection Observer API.
* **Zero Dependencies:** Built entirely with vanilla web technologies for maximum performance and instant load times.
* **Responsive Design:** Mobile-first architecture ensuring seamless scaling across all device sizes.

## Technology Stack
* **HTML5:** Semantic structure, Open Graph meta tags, and inline SVG rendering.
* **CSS3:** Advanced gradients, backdrop-filters, CSS Grid/Flexbox, and keyframe animations.
* **Vanilla JavaScript:** DOM manipulation, custom cursor tracking, and scroll-event listeners.

## File Structure
* `index.html`: Core markup, meta-data, and structured content.
* `style.css`: All responsive styling and animation keyframes.
* `script.js`: Preloader logic, scroll observation, and interactive cursor mechanics.
* `LICENSE`: MIT License documentation.

## Deployment Quick Start
This project is fully static and requires no build steps or package managers. 

1. Clone the repository to your local machine.
2. Open `index.html` in any modern web browser to view the local build.
3. Deploy directly by uploading the repository to hosting platforms like Netlify, Vercel, or GitHub Pages.
